# Free deployment

This is a static website: HTML + CSS + JavaScript + local video assets.

## Before publishing
1. Open `index.html`.
2. Replace `your-email@example.com` with your real email.
3. Add more projects in `script.js` when ready.
4. Keep video files reasonably compressed for web playback.

## Free hosting
GitHub Pages is a good free option for this type of static site. Create a GitHub repository, upload these files, then enable Pages from the repository settings.

The site can initially use the free `github.io` address. A custom domain can be added later when you have the budget.
